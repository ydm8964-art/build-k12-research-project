# 真实照片证据与Word插入规范

本文件适用于课题过程照片、课堂照片、学生作品照片、教研活动照片、校外调查照片、成果推广照片及照片证据汇编。真实照片是“研究发生过”的过程证据，不自动等于“研究有效”的效果证据。

## 一、先登记，后插入

收到照片后先保留只读原件，再建立照片证据登记。每张照片至少登记：

- 照片证据ID，例如`PHO-2026-001`；
- 原文件名、原件SHA-256、派生文件及其SHA-256、拍摄/取得日期、地点、活动名称和研究阶段；
- 拍摄者或来源、画面内容、涉及对象及匿名编码；
- 对应研究问题、活动、案例、材料和正文结论；
- 告知/同意状态、允许使用范围、可识别人物处理方式；
- 规范图题、替代文本、插入文件名和必要的处理记录。
- 原件是否随包交付；随包时登记交付内相对路径，不随包时登记保管责任人、受控定位和核验日期。报送/公开派生件仍须放入交付包并校验哈希。

拍摄日期优先来自真实活动记录和照片原件；EXIF只能辅助核对，不能作为唯一依据，更不能补造或倒改时间。公开副本应清除GPS、设备、作者等无关元数据，受控原件不做破坏性覆盖。

## 二、真实性和处理边界

- 只使用用户或学校提供、且能说明来源的真实照片；不得生成照片冒充课堂、学生作品、教研活动或专家指导现场。
- 不把摆拍、补拍或其他项目照片写成当时的自然实施过程；确为补充记录时明确标注。
- 允许等比例缩放、适度裁切、亮度/对比度校正、旋转、压缩、人物打码和敏感区域遮挡；每项实质处理进入变换记录。
- 不得移动、增删或合成画面内容来改变证据含义；不使用美化滤镜制造不存在的细节。
- 同一照片重复用于不同活动、不同日期或不同结论时必须拦截；确需复用时使用同一证据ID和一致说明。

## 三、知情同意与人物隐私

照片中有可识别学生、教师、家长或校外人员时，核对学校制度及告知/授权范围。未获公开授权的可识别照片只能进入受控工作版或报送版；匿名版、公开版采用背影、远景、裁切、打码，或替换为不含可识别人物的作品/环境照片。

图题和替代文本不写学生真实姓名、学号、联系方式或家庭信息。人员—匿名编码映射表与照片分开保存。撤回授权时，根据照片ID定位并同步删除或替换所有派生版本和正文引用。

## 四、不同材料中的照片安排

| 材料 | 照片用途 | 放置原则 |
|---|---|---|
| 申请书/匿名活页 | 一般不需要 | 只有官方表格允许且确属前期基础时使用；匿名活页不得暴露身份线索 |
| 开题报告 | 开题会议或条件基础 | 以官方要求为准，会议照片通常放附件，不替代专家签名和意见 |
| 课堂观察/活动记录 | 证明实施情境和过程 | 与同日记录表、教案、任务单对应，图题写活动而非笼统“课堂照片” |
| 中期报告 | 展示代表性过程 | 少量选取关键节点，正文引用证据ID，完整照片进入附录证据册 |
| 教学案例/案例集 | 展示任务、过程、作品、评价 | 已实施案例可插入；开发稿只保留结构化待插图备注，不得伪装为实施照片 |
| 研究报告 | 支撑研究过程或典型案例 | 只放与论证直接相关的代表图；效果结论仍以测评、作品量规等数据为主 |
| 结题附件/照片证据册 | 完整归档 | 按阶段—活动—证据ID排序，提供照片索引、图题、授权状态和对应材料 |

不要为“看起来丰富”在每页堆图。优先选择能证明关键研究节点的照片：活动准备、任务实施、学生产出、评价反馈、反思改进和成果应用。相似连拍只保留最能说明问题的1—2张，其余进入受控原件目录。

## 五、没有照片时的备注格式

工作稿可以在预定位置放结构化备注：

`【待插入真实照片 PHO-2026-001｜活动：××课堂任务实施｜需要：日期、地点、拍摄者、授权状态、对应记录表】`

备注必须说明“需要什么真实照片和缺什么信息”，不能只写“此处插图”。备注进入待人工事项清单。报送终稿、公开终稿和标记“可直接使用”的文件不得保留待插图备注；如果真实照片仍未取得，应删除相关证据性表述或将该材料标记为`待照片`。

## 六、Word插入和图题合同

1. 优先使用内嵌型图片，不使用容易跨软件漂移的浮动环绕；官方模板另有要求除外。
2. 图片保持原始长宽比，不拉伸、不无依据放大低分辨率图；插入后以200%检查清晰度。
3. 单图一般不超过版心宽；两图并排时采用等宽的重复记录布局，明确列宽和间距，避免图片或题注贴边。
4. 图片段落居中，图片段落与紧随其后的图题保持同页；不得让图题单独落在下一页。
5. 图题放在图片下方，全文连续编号或按章节编号，例如：

   `图 4-2 学生小组开展××任务（证据ID：PHO-2026-014；2026年10月18日；××教室）`

6. 需要补充来源、授权或处理说明时用图下注，不把过长说明全部塞进图题。
7. 正文使用“见图4-2”或证据ID交叉引用，不写“如下图”“上图”这类分页后可能失效的指代。
8. 图号使用Word题注/SEQ字段，正文引用使用REF字段；自动化输出后物化字段显示值，修改图片顺序后重新编号和更新交叉引用。
9. 每张图设置有意义的替代文本，描述活动和证据用途，不用文件名或学生姓名充当替代文本。
10. 图题、正文和证据台账中的日期、活动、地点、ID必须完全一致。

## 七、照片证据册推荐结构

- 封面和项目身份；
- 使用说明、隐私级别和照片选择原则；
- 照片索引表：图号、照片ID、日期、活动、对应材料/案例、授权状态、页码；
- 按研究阶段编排的照片页；
- 必要的授权/审批状态说明（不公开敏感授权原件）；
- 原件目录和哈希清单；
- 版本记录和待补事项。

每个照片记录必须能独立理解。只有图片而无图题、日期、证据ID和对应活动的“照片堆”，不属于可验收证据册。

## 八、最终验收

- 图片数量与照片登记表一致；所有图题连续且正文交叉引用有效；
- 每张证据照片都有唯一ID、真实日期、活动、来源、授权状态和替代文本；
- 没有重复照片被赋予不同日期或活动；没有外部网络图片冒充现场照片；
- 匿名/公开版已处理人脸、姓名牌、校服身份、黑板信息、定位和文件元数据；
- 图片清晰、不变形、不越界，图题与图片同页，无孤立大空白；
- 逐页渲染查看全部照片页，并运行图片、无障碍、内容、隐私和照片证据审计；
- Word、PDF、照片登记XLSX与受控原件目录使用同一照片ID。
