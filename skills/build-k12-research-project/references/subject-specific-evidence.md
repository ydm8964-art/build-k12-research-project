# 中小学全学科真实证据与专项核验

本文件用于把通用课题证据链转换为具体学科可以执行、可以核验的材料要求。生成选题、教学设计、案例、研究工具、数据表、照片任务、研究报告和根目录注意事项文件时，先识别主学科，再采用对应学科行；跨学科课题同时采用主学科行和实际涉及的关联学科行，但不得为了显得“综合”而堆叠无关材料。

## 一、通用底座

任何学科都至少保留：课程标准与教材定位、真实问题基线、研究工具及空白版、原始填写/录音/观察/测评、变量或评分口径、实施记录、学生成果、评价与反思、照片/电子证据登记、数据分析、成果证明和时间/版本/授权信息。学科专项要求是在这套底座上增补，不是取代通用证据。

真实证据必须能回答五个问题：谁在何时何地开展了什么活动；使用哪个版本的工具或教学材料；产生了什么原始记录；如何从原始记录得到结论；公开或报送是否满足隐私、安全、版权和署名要求。

## 三、照片与非照片证据的边界

照片只能证明照片中可见的真实情境，不能单独证明学习效果。不同学科优先画面如下：

- 语文、英语：讨论、朗读/展示、写作修改、作品反馈；听说表现还要有经授权的音频或视频。
- 数学：操作探究、思路交流、解题过程和错因订正；总分变化必须由测评原件和数据表支持。
- 理化生/科学：器材准备与安全、变量控制、原始观察/测量、实验产品或记录；结论必须回到原始数据。
- 政史地：史料/地图/数据研读、议题讨论、田野调查和成果展示；来源与时间信息必须单独登记。
- 体育：安全检查、热身、技术练习、测试流程和反馈；健康筛查、成绩和异常记录不应直接公开。
- 音乐、美术：排练/创作过程、修改痕迹、作品/展演和评价；同时登记资源及作品授权。
- 信息科技/通用技术：真实操作环境、设计制作和调试；代码、版本日志、截图/录屏是独立电子证据，不能全部用摆拍替代。
- 劳动/综合实践：安全培训、规范操作、协作过程、产品/服务和真实使用反馈。
- 心理健康/德育：优先拍摄不识别个人的环境、材料和集体活动远景；敏感咨询、量表答案和个案不拍摄、不公开。

每张照片仍须登记照片ID、原件、SHA-256、日期、地点、活动、拍摄来源、授权/人物处理、对应材料和图题。屏幕截图、扫描件、学生作品照片、录屏和音频分别登记证据类型，不能全部混称为“活动照片”。

## 四、学科专项完成门槛

1. 申请阶段至少明确主学科、学段、课程标准/教材范围、主要学习成果、拟用评价方法和专项风险。
2. 实施阶段至少取得该学科的真实过程原件、可执行量规/工具、版本记录和安全/授权记录。
3. 结题阶段每个学科结论都能回溯到相称的原始证据，公式、语言、史实、地图、实验、动作、艺术资源或代码等由适格人员/权威来源复核。
4. 学科专家复核不能由格式审计替代；自动生成文件中的专项清单是最低检查框架，不是专业结论本身。
