# 每个课题必做的实时政策检索与快照

## 一、不可复用上一个课题的检索结论

每次新建课题、切换申报年度/管理单位、进入正式提交或结题打包前，都重新联网检索。不得只改年度继续使用旧通知、搜索摘要、公众号转发、培训截图或往年附件。

按以下顺序查找并打开原文及附件：

1. 目标管理单位官网、通知公告和科研/基础教育栏目；
2. 贵州省教育厅“通知公告”和“科学研究”栏目；
3. 黔东南州教育行政/教科研管理部门公开入口及学校收到的正式转发通知；
4. 通知指定的贵州省教育科研管理平台；
5. 课程标准、国家政策等上位依据的教育部或国家机关官网。

检索词至少同时包含“年度＋地区/管理单位＋课题类型＋申报/结题＋通知/附件/模板”。必须打开来源页面，核对发布日期、发文机关、适用对象、原附件名称和下载内容。若州级通知只在内部群、OA或学校下发，登记来源和保管人，并把真实文件放入受控目录；找不到当年模板时保持`blocked-template`。

## 二、每次形成独立核验输入

把本次实际检索结果写入独立JSON；字段示例见[policy-search-input.example.json](policy-search-input.example.json)，复制后必须用本项目本次检索结果替换。至少包含：

- `search_run_id`：本项目本次检索唯一编号；
- `searched_at`：实际检索日期；
- `official_portals_checked`、`search_queries`；
- 管理单位、适用年度、截止日期、申报/结题方式；
- 申请资格、类别、周期、限额、匿名和重复申报要求；
- 线上上传、纸质份数、纸张方向、双面/装订、档案袋、命名、大小和签章规则；
- `sources`：通知、管理办法和每个官方模板的ID、标题、URL/受控位置、核验日期、适用年度；
- `notice_source_ids`、`template_source_ids`、教师层面必交材料ID；
- 学校/县/州统一汇总等不由单个教师制作的`external_submission_items`。

运行：

```bash
python scripts/record_policy_snapshot.py \
  --manifest delivery-folder/project-manifest.json \
  --root delivery-folder \
  --input current-policy-search.json
```

脚本在`01政策与立项/`保存不可覆盖的当年要求快照，登记相对路径和SHA-256，并把主清单升级到1.5。正式预检要求检索日期距项目当前日期不超过7天；超过7天、通知/附件更新、管理单位改变或报送系统补充要求发布时重新检索并登记新快照，旧快照改为`expired`或保留为历史版本。

## 三、2026年贵州省基线示例（不能替代下一次实时检索）

截至2026-08-14，贵州省教育厅2026年度通知明确：申报期为2026-04-15至05-09；参评教师于04-22至04-27上传贵州省教育科研管理平台；纸质材料包括申请书3份、设计论证活页1份、汇总表1份；申请书和活页使用A3双面印制、中线骑缝装订，汇总表A4；黔东南州省级申报名额75项；青年课题申请人不超过40周岁；必须使用2026年度申请书和活页。原文入口：`https://jyt.guizhou.gov.cn/zwgk/tzgg/202601/t20260128_89348284.html`。

该示例只说明“年度要求会变化”。以后制作任何课题仍须重新搜索、下载当年附件并以实际管理单位的补充通知为准。
