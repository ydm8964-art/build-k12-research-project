# 用户参考材料格式与适用性目录

本目录来自一套历史完整参考材料包，仅记录已经观察到的材料角色、栏目链、表格组织和风险经验。只有用户提供同类参考材料时才据此比对；旧项目身份、数据、日期、作者、结论和图片不得进入新项目。

参考文件夹中没有可直接复用的XLSX数据工作簿。因此电子表格只能依据新课题的变量编码、真实原始数据和[spreadsheet-standards.md](spreadsheet-standards.md)新建，不能从Word统计表反向猜造原始数据。

## 二、格式适用性分级

- `official-authority`：仅当年官方附件可作为精确版式权威，使用工作副本原位填写。
- `structural-reference`：教师/学生工具、分析报告、框架、教案和案例集只提供栏目与表格角色；重新生成时按本Skill格式合同制作并逐页渲染。
- `content-example-only`：已填写访谈、观察、案例叙述和旧数据只用于理解材料关系，不复制事实。
- `unsafe-as-template`：无文本层扫描件、无说明照片册、缺实施元数据的案例集、含外部作者或旧项目身份的文件不得直接作为新项目模板。

任何参考文件先登记`fitness_class`。只有`official-authority`可以配置`official-exact`；`structural-reference`使用相应通用profile，不能为了“像参考材料”而复制缺陷。

## 三、从参考材料确认的格式底线

1. 申请、开题和结题管理表必须保留封面、提示、意见、签章和空白页区，不压缩或假填。
2. 工具既要有可打印空白版，也要有电子录入/编码版；填写后的记录另存，不覆盖空白工具。
3. 统计报告用三线表，但每一数字必须有XLSX来源区域、N值、分母和精度。
4. 常态课和示范课二选一；前者以大表为主体，后者以长文本章节为主体。
5. 案例集必须先统一栏目，再汇编；目录、案例数、页码、状态和证据索引在终稿重新生成。
6. 原图、教材图、地图、网络资源图和真实课堂照片分别登记；只有真实现场照片进入照片证据链。
7. 参考材料渲染中出现字体缺失、空白过多或表格密度不合理时，只保留结构，不复制视觉缺陷。

## 四、逐文件格式抽取结论

已对参考包中的22份DOCX和2份DOC转换工作副本逐段提取有效字体、字号、加粗、对齐、首行缩进、行距、段前段后、页面与表格属性；3份PDF用于结构和视觉旁证，不反向猜测可编辑样式。可复核时运行`scripts/extract_docx_format_profile.py`输出JSON证据。

抽取结果证明历史材料不是同一套稳定格式：官方申请表主要出现宋体10.5/12磅及黑体15磅；开题正文出现宋体16磅、固定30磅行距；部分分析报告和框架出现苹方/冬青黑体等Mac字体、12磅、固定20磅行距和24磅首行缩进；长文本教案又混有方正小标宋、方正仿宋、12/16磅及多种行距；表格式教案和研究工具多为宋体10.5—12磅。直接继承任何一份都会导致整套材料不一致，Mac专用字体还会在Windows替换和漂移。

因此旧样本只决定栏目、表格角色和材料逻辑；非官方材料统一执行[26项材料固定版式合同](material-format-contracts.md)，官方材料仍以当年真实原模板为绝对权威。这个决策保留了参考包的方法，同时消除了不可移植字体、同级标题多字号、正文有无缩进不一和表格密度不一致等缺陷。
