# 本地完整材料提炼的结构母版

本文件提炼自一套历史完整参考材料包。只复用结构、工作方法和检查经验；不得复用原项目的题目、个人姓名、学校、项目编号、调查数据、访谈内容、图片或活动事实。

## 一、这套材料的实际构成

1. 身份与立项：省级申请书、州级立项通知。
2. 组织实施：州级开题报告。
3. 空白工具：教师问卷、学生问卷、教师访谈提纲、课堂观察表。
4. 原始证据：8 份教师访谈记录及手写原件、5 节课堂观察记录及手写原件、实践活动照片。
5. 诊断分析：教师问卷、教师访谈、常态课堂观察三类分析报告。
6. 干预框架：跨学科主题学习设计原则、要素、流程和评价框架。
7. 课堂实践：常态课堂表格式教案和示范课长文本式教案。
8. 成果汇编：21 个跨学科案例组成的案例集。

这是一套较完整的“研究过程与实践成果包”，但不能自动等同于任何年度的“正式结题全套”。生成新项目时仍须根据当年清单补入研究报告、中期材料、结题申请、成果证明等。

按全生命周期反向核对，参考文件夹还未提供可直接复用的：匿名活页独立成品、研究伦理/告知同意材料、数据管理方案、变量编码与真实数据XLSX、学生问卷分析或前后测结果、工具预测试与修订记录、实施保真度台账、教研/培训/会议过程记录、中期报告、正式研究总报告、结题申请/鉴定书、成果目录、应用/推广证明及整套交付索引。以后生成`full-lifecycle-kit`时必须补建这些角色，不能因为参考文件夹没有就省略；确实不适用的材料登记覆盖豁免和依据。

进一步复核还暴露出四类可迁移风险：填写后的访谈/观察扫描件仍可能沿用“提纲/记录表”笼统文件名且没有文本层；案例集叙述了大量已实施效果但普遍缺少日期、班级、教师和人数等实施元数据；正文引用照片而案例集本体无图片；个别课例署名者不在立项成员表中。新项目必须分别通过记录ID与转写索引、案例状态门槛、照片台账和贡献/授权登记解决，不能只修改文件名或正文措辞。

## 二、申请书母版

参考材料的栏目链条为：

1. 封面项目身份；
2. 负责人承诺；
3. 填写说明和数据表说明；
4. 项目数据表、负责人和成员；
5. 近五年相关成果；
6. 课题设计论证：选题依据、研究内容、思路方法、创新之处、预期成果、参考文献；
7. 完成课题的条件和保障；
8. 阶段性成果与最终成果；
9. 推荐人、责任单位和管理部门意见。

应用时先服从当年官方模板。特别检查题目字数、关键词数量、成员上限、成果数量、匿名活页、打印方式和签章要求；这些旧表规则不能默认沿用。

## 三、开题报告母版

参考材料包含：封面；开题时间地点；3—5 名专家及外校专家要求提示；与会人员；5000 字左右的开题报告；1000 字左右专家评议；重要变更；负责人单位和管理部门意见。

内容主干为：选题依据 → 研究意义与现状 → 核心概念 → 目标、对象、内容和重点难点 → 基本思路与方法 → 可行性 → 分阶段计划 → 预期成果与效益 → 组织分工。

开题必须对申请书做“细化”，而非换题重写。参考材料出现了申报/立项前调查与正式计划交叉的问题；新项目要将此类活动明确列为“前期预调查/已有研究基础”，或如实办理计划调整。

## 四、工具组合母版

参考材料形成了三角互证组合：

- 教师问卷：23 题、5 部分——基本情况，认识，实施情况，效果与困难，开放建议；含单选、多选、五级量表和开放题。
- 学生问卷：16 题、4 部分——基本情况，学习情况，学习效果，困难与建议；语言更简洁，量表更少。
- 教师访谈：基本信息＋5 个主问题，解释理解、实施、组织、学生表现、困难与建议。
- 课堂观察：6 个观察维度——学科联系、生活情境、任务设计、活动组织、学生参与、评价方式；等级记录＋叙事记录。

新课题不能照搬题数和维度。先建立“研究问题—维度—指标—题号—分析方法”矩阵，再决定工具。发布前做连续编号、漏字、选项互斥与穷尽、量表方向和适龄语言检查。参考材料中曾出现“课堂、小组、纸笔”等词漏首字和观察记录编号缺项，必须通过文字校对拦截。

## 五、原始证据与分析母版

每一种工具形成四件套：

1. 空白工具；
2. 已填写原件或原始数据；
3. 数据录入/访谈编码/观察汇总；
4. 分析报告。

参考材料以大样本教师问卷、8 名教师访谈、5 节课堂观察互相解释。新项目不得复用这些数量；由研究范围和真实可得对象确定。分析报告采用“基本情况—分维度数据表—解释—不同证据互证—主要问题—干预启示—局限”的结构。三线表适合统计结果；每表给出 N 值和口径，多选题说明合计超过 100%。

学生问卷若用于证明学生效果，必须补齐真实回收数据、分析报告，最好设计基线/后测或多时点证据。只有空白学生问卷不能支撑“学生能力提高”的结论。

## 六、干预框架母版

参考材料的六项原则可迁移为通用检查维度：主学科主体性、核心素养导向、真实情境、合理融合、实践探究、多元评价。

参考材料的 11 个设计要素为：学习主题、主题背景、课程内容、关联学科、素养目标、核心问题、学习任务、学习活动、学习成果、学习评价、教学反思。

通用流程为：确定主题 → 分析课程 → 制定目标 → 创设持续情境 → 提出核心问题 → 分解递进任务 → 组织探究实践 → 形成成果 → 展示与多元评价 → 反思改进。

评价示例曾采用知识运用 25%、问题分析 20%、实践探究 20%、合作参与 15%、成果表达 15%、反思改进 5%。这只是可调整示例；新课题应根据目标和任务重设权重，并保证合计为 100%。

## 七、两类教学设计母版

### A. 常态课堂表格式

适合常规课和 8—10 分钟跨学科微环节。参考材料通常是一张纵向大表，栏目包括：授课教师/学校、课题、版本、对象、课时、课标、教材、学情、目标、重难点、教法学法、资源、教学过程（环节/教师活动/学生活动/设计意图）、跨学科微任务、小结、板书、作业、评价反思。

微环节必须给出真实问题、限定时间、具体产出和简短量规，并写清“主学科知识—关联学科方法—产出”的联系。它不能只是教师补充另一学科知识。

### B. 示范课长文本式

适合公开课、优质课和典型成果。参考栏目为：教学理论依据与理念、课标原文与行为动词分析、教材、学情、教学思路、核心素养目标、重难点、方法、师生准备、教学过程表、板书、基础/迁移作业、反思、参考文献。可增加目录和教学路径图。

两类教案不能混成一份臃肿模板。根据用途选型，并保持同一案例的目标、任务、成果和评价一致。

## 八、案例集母版

参考案例集含 21 个案例，覆盖模型制作、模拟实验、乡土调查、地方文化、生态环保等类型。典型案例骨架为：

1. 案例基本信息；
2. 主题背景；
3. 学情分析；
4. 学习目标；
5. 跨学科内容分析；
6. 核心问题、驱动性问题和任务；
7. 师生准备、材料与安全；
8. 原理或方法；
9. 教学实施过程；
10. 学生设计/调查/实验记录表；
11. 测试、评价与改进记录；
12. 学习成果；
13. 学生反馈；
14. 教师反思与拓展。

案例开发稿可以写“预期成果”；实施案例必须替换为真实作品、记录和评价。模型案例应声明教学模型的局限和安全边界。案例集完成后更新目录域并核对实际页码，不能沿用编辑过程中的旧页码。

## 九、从诊断到成果的闭环

参考材料最有价值的迁移路径是：教师虽认可价值但认识和实施不足 → 问卷、访谈、观察确认主题、任务、活动和评价问题 → 建立操作框架 → 开发表格式和长文本式教案 → 形成多类型案例集。

新课题必须逐条写明“诊断发现—对应策略—实施载体—评价方式—证据—结论”。若前面发现评价单一，后续就必须出现可用量规和评价记录；若发现教师缺少案例，成果就应包括可复用的案例和使用说明。
