# 贵州省与黔东南州适配规则

## 一、来源优先级

涉及申报、开题、中期、结题和成果鉴定时，优先核验：

1. 贵州省教育厅、贵州省教育科学规划领导小组办公室等省级官方来源；
2. 黔东南州教育局、州教育科学研究所等州级官方来源；
3. 县市教育行政或教研部门正式通知；
4. 学校转发通知和内部时间安排。

上级要求与具体申报通知不一致时，以该项目当年正式通知、管理办法和附件表格为准，并保留来源文件。

## 二、年度核验清单

每次新项目实时核验：申报对象和限额、课题类别、申报条件、课题指南、禁限项、研究周期、申报系统、材料份数、匿名活页要求、签章流程、截止日期、开题期限、中期要求、成果形式、结题条件、延期与变更规则。

不得沿用旧年度表格中的年份、文号、类别、页数限制或承诺日期。无法取得官方附件时，先生成内容底稿并标注“待套用当年官方模板”。

核验结果必须写入项目主清单的`submission_requirements`：管理单位、年度、核验日期、通知来源ID、模板来源ID、必交材料ID、匿名要求、报送方式、命名/大小/份数规则。来源同时登记`verified_at`和`valid_for_year`。只有通知与模板均来自可定位的官方原件且适用年度一致时，状态才可标记`verified`；新通知或修订附件出现后，旧快照标记`expired`。

## 三、官方入口与时效快照

- 省级通知优先从贵州省教育厅网站的通知公告及贵州省教育科学规划相关栏目发现，并回到通知正文和原附件核验。示例入口：[2026年度贵州省教育科学规划课题申报通知](https://jyt.guizhou.gov.cn/zwgk/tzgg/202601/t20260128_89348284.html)。
- 管理规则可从贵州省教育厅发布的《贵州省教育科学规划课题管理办法》及其官方解读核验；年度通知与管理办法冲突时，以现行管理办法和当年专项通知共同判断。示例入口：[《贵州省教育科学规划课题管理办法》解读](https://jyt.guizhou.gov.cn/zwgk/zcjd/202005/t20200527_88908236.html)。
- 黔东南州公开信息可从[黔东南州人民政府教育重点领域信息公开栏目](https://www.qdn.gov.cn/zwgk_5871642/zdlyxxgk/jy_5872114/)发现，再核验具体发布机关、正文和附件；门户栏目本身不等于当年申报通知。
- 州、县或学校通知如只在内部工作渠道流转，必须取得原始PDF/DOC/通知截图及附件，并登记发布单位、接收日期、转发链和校内提前截止时间。网页未检索到不等于该要求不存在。
- 截至2026-08-12的核验示例：2026年度省级课题通知为时效快照，只能帮助识别当年类别、名额、申报窗口和附件要求；跨年度生成时必须重新检索，不能沿用该示例。
- 所有网页链接在每次任务开始时重新打开核验发布日期、适用对象、附件版本和有效性；链接失效时保留原件哈希和获取记录，不凭搜索摘要填写政策事实。

## 四、地方化但不标签化

可结合黔东南的民族文化、乡土资源、城乡学校条件、寄宿制、普通话与民族语言环境、生态文明、非遗、劳动教育和区域数字资源，但必须与真实校情、学科内容和研究问题相关。未经教师确认，不假设学生族别、家庭条件、语言能力或学校资源。

## 五、政策引用

记录政策全称、发布机构、发布日期、文号、有效状态和官方链接。课程标准引用现行版本；引用条文以原文核验为准。政策只能说明方向与依据，不能替代校本问题证据。
