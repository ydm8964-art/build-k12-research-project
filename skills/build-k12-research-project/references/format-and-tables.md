## 一、格式权威顺序

按以下顺序确定格式，不得把通用排版覆盖到官方表格：

1. 申报或结题当年官方原始附件及填表说明；
2. 用户明确指定的同类Word参考文件；
3. 本Skill从用户材料提炼的同类格式合同；
4. 没有任何模板时才使用通用中文教育科研格式。

“符合格式”首先是栏目、顺序、纸张、页数、匿名、签章和打印要求符合，其次才是美观。官方模板即使版式不够美观，也只能在不改变结构的范围内填写和修复明显溢出。

## 二、生成前版式合同

每份Word材料生成前记录一个格式合同：

- 格式模式：`official-exact`、`research-form`、`analysis-report`、`lesson-table`、`lesson-long`、`casebook`、`evidence-sheet`；
- 材料包注意事项使用`attention-items`；允许A4横向，便于呈现真实性、时间和责任人控制表；
- 权威模板的绝对路径、版本、年份和SHA-256；
- 输出格式、纸张、方向、页边距、分节、页眉页脚、页码和打印方式；
- 封面、目录、标题层级、正文字体、行距、首行缩进和段前段后；
- 表格数量/角色、总宽、列宽、合并方式、边框、内边距、表头重复、分页规则；
- 图片尺寸、题注、来源和隐私处理；
- 真实照片的证据ID、日期/活动、图题编号、正文交叉引用、替代文本、授权和人物处理；
- 可编辑槽位、签字盖章区、匿名区和不可改动区域；
- 页数/字数限制和最终验收方式。

模板发生变化时重新提炼合同，不能拿旧合同填新表。

## 三、分材料格式路由

| 材料 | 格式模式 | 默认产物 | 核心格式要求 |
|---|---|---|---|
| 申请书、活页、结题申请、鉴定书 | `official-exact` | 原模板格式或DOCX | 从官方源文件复制工作件，原位填写；栏目、表格、分节、签章区和匿名要求不变 |
| 开题、中期、变更等管理表 | `official-exact`优先 | DOC/DOCX | 保留管理部门封面、提示语、意见栏和页数限制 |
| 实施方案、研究报告、阶段总结 | `analysis-report` | DOCX | A4纵向；正式标题体系；正文与图表连续编号；需要时有封面、目录和页码 |
| 问卷、访谈提纲、观察表、记录表 | `research-form` | DOCX＋数据录入XLSX | A4纵向；填写区充足；选项和量表清晰；一份空白工具可直接打印使用 |
| 调查、访谈、观察分析 | `analysis-report` | DOCX＋统计XLSX | A4纵向；结果表采用三线表；每表有表号、名称、N值和口径 |
| 教学设计基本框架 | `analysis-report` | DOCX | 正文说明＋要素表、流程表和评价表；表格宽度适配版心 |
| 常态课堂教学设计 | `lesson-table` | DOCX | A4纵向；基本信息＋大表；教学过程四列；跨学科微环节有时间、任务、产出和评价 |
| 示范课/优质课教学设计 | `lesson-long` | DOCX | A4纵向；长文本标题体系＋教学过程四列表；可含目录、路径图、参考文献 |
| 单个案例 | `lesson-long`或`lesson-table` | DOCX | 根据用途选型；实施案例附任务单、作品索引和量规 |
| 案例集、成果汇编 | `casebook` | DOCX，必要时PDF | 统一封面、自动目录、案例编号、页码、表图编号和附录；每个案例从奇数页或新页开始由需求决定 |
| 照片、作品、证明汇编 | `evidence-sheet` | DOCX/PDF | 每项有证据编号、日期、场景、说明和来源；图片等比例，不拉伸 |
| 材料包注意事项与待办 | `attention-items` | DOCX | A4横向；根目录`00_`开头；阻断、照片、真实原件、时间检查和建议增强分表；表头跨页重复 |

若同一通知指定A3双面、中缝装订或特殊页数，严格按通知执行，不强制A4。

没有官方或用户指定模板时，可从Skill的`assets/templates/`复制下列已清除旧项目信息的结构母版；生成脚本位于`scripts/build_generic_docx_templates.py`，母版需要重建时运行脚本后必须重新审计和渲染。

| 文件 | 对应模式 | 适用范围 |
|---|---|---|
| `research-form.docx` | `research-form` | 问卷、访谈、观察、测评和记录工具 |
| `analysis-report.docx` | `analysis-report` | 调查分析、阶段总结、研究报告正文 |
| `lesson-table.docx` | `lesson-table` | 常态课、大表式教学设计 |
| `lesson-long.docx` | `lesson-long` | 示范课、优质课、长篇案例 |
| `casebook.docx` | `casebook` | 案例集、成果汇编 |
| `evidence-sheet.docx` | `evidence-sheet` | 照片、作品和证明证据册 |
| `attention-items.docx` | `attention-items` | 材料包真实性、缺件、时间逻辑和增强建议控制文件 |

通用母版不是省州当年官方附件，不能替代申请书、开题表、结题申请、鉴定书等`official-exact`文件。母版中的方括号字段在终稿必须清零；字体按当年通知或用户环境替换，表格宽度和分页仍需逐页复核。

真实照片的采集、备注、隐私和证据规则同时读取[photo-evidence-and-placement.md](photo-evidence-and-placement.md)。课件截图、教材插图、地图和网络资料图必须标注来源，不得当作真实研究现场照片。

## 四、Word表格硬规则

1. 表格总宽不得超过版心；明确设置`tblW`、`tblGrid`和每个单元格宽度，不依赖自动调整。
2. 列宽按信息量分配：序号、等级、分值和日期列窄；描述、教师活动和学生活动列宽。
3. 表头行启用跨页重复；表头文字水平和垂直居中。
4. 不设置可能截断文字的固定行高。短记录行可设最小高度；长教学过程行允许自然增高。
5. 单元格必须有内边距。短标签居中，长段落左对齐或两端对齐并顶端对齐。
6. 合并单元格只用于分组标题、表单标签和语义跨列，不能用于原始数据表和统计计算区。
7. 短行尽量禁止跨页拆分；内容超过一页的长行允许拆分，避免前页出现大块空白。
8. 表格前后保留清晰间距；表题与表格不分离；续表保持相同列宽和表头。
9. 同一文件内同类表格使用同一边框、字号、内边距和表头样式。
10. 最终渲染中不得出现越界、文字贴边、表头孤立、单元格被截断或整页异常空白。

## 五、分类型表格规则

### 1. 官方申报表

从原模板制作工作副本，只替换可填写槽位。不要重建表格、删除空白行、改变合并关系或压缩签章区。内容过长时优先精简文字；不得私自缩小到难以阅读的字号。

### 2. 问卷量表

首列放完整题项，等级列窄且等宽；等级名称完整可见。使用`□`或官方既有控件，不混用多个勾选符号。每题选项与题干保持在同页附近；开放题保留可书写空间。

### 3. 观察与访谈记录表

基本信息采用紧凑标签区，主体记录区留足行高。观察维度、观察点、等级列清晰分开；叙事记录项连续编号。电子填写版不得用连续下划线挤压文字，可用无底纹表单格。

### 4. 统计三线表

一般只保留顶线、表头底线和底线，不使用竖线；数值列小数位一致。表题置于表上方，表注置于表下方。频数用整数，比例使用同一精度；合计和样本量可复核。

### 5. 教学过程表

推荐“环节—教师活动—学生活动—设计意图/评价”四列。环节列最窄，教师活动略宽于学生活动或按内容调整，设计意图适中。不要把整篇教案塞进单个超长单元格；在活动单元格内使用真实编号和项目符号。

### 6. 评价量规

至少包含评价维度、可观察标准、等级/分值和评价主体。权重合计100%；同一等级在各维度含义一致。量规横向过宽时优先改为纵向分块，不直接缩小至不可读。

## 六、文档验收门槛

1. 官方模板：与原模板做分节、页边距、表格、页眉页脚和签章区结构比对。
2. 结构检查：运行本Skill的`audit_docx_format.py`；对模板填充件使用`--reference`。
3. 视觉检查：使用文档能力渲染全部页面，100%查看每页；修改后重新渲染。
4. 字段检查：目录、页码、题注和交叉引用刷新；无法刷新时设置打开Word后更新并明确提示。
5. 终稿检查：清除旧题目、旧姓名、占位符、批注、修订痕迹和错误元数据；签章空位按要求保留。
6. 图片检查：照片以内嵌方式稳定排版，图题和照片同页，图号/照片ID连续，替代文本完整，匿名/公开版人物与元数据处理完成。

结构脚本通过不等于格式合格；只有结构审计和逐页视觉检查都通过，才能标记“可直接使用”。
