# 研究方法、数据与证据

## 一、方法选择

- 文献研究：界定概念、梳理进展和建立理论依据。
- 调查研究：了解群体分布、态度、行为和需求。
- 访谈：解释原因、过程、体验和典型事件。
- 课堂观察：记录实际教学行为，减少只依赖自报数据。
- 行动研究：计划—行动—观察—反思，至少体现一轮改进，条件允许时多轮迭代。
- 案例研究：深入呈现代表性课堂或学生变化，不据单个案例外推总体。
- 实验/准实验：需要清楚说明分组、前测、后测、控制条件和伦理；条件不足时不要滥用“实验法”。
- 作品分析：用量规分析作业、项目成果、表达或表现性任务。

凡声称某策略产生效果，同时记录实施保真度：核心成分是否执行、实际课次/时长、覆盖对象、缺席流失、执行质量和偏离原因。策略未充分实施时，不能只依据结果评价策略本身。

## 二、工具—问题对应

先做矩阵：研究问题 → 变量/维度 → 可观察指标 → 数据来源 → 工具题号 → 分析方法 → 预期证据。一个关键结论尽量由两类以上数据支持，但不要为了“三角互证”添加无关工具。

同时标明工具属于“现状/需求、过程监测、结果评价”哪一类。现状问卷和教师主观评价不能单独证明干预有效；学生效果需要前后测、等值任务、多时点观察、作品量规或其他真实可比较证据。

## 三、数据边界

允许生成：空白问卷、访谈提纲、观察量表、数据录入表、变量编码表、模拟计算示例（必须醒目标注“示例数据”）、分析公式和报告骨架。

禁止生成并冒充真实材料：实际发放与回收数量、学生成绩、百分比、访谈原话、观察记录、学生作品、照片说明、专家意见、获奖或推广证明。

## 四、分析最低要求

- 给出样本来源、时间、选取方式、有效标准和伦理处理；
- 频数与百分比相互核对，百分比说明小数位；
- 多选题写明分母；前后测使用同一或等值标准；
- 质性材料说明编码方式、主题形成过程和代表性证据；
- 访谈说明匿名编号、编码者、复核过程、代表性引语和反例；少量访谈不换算为总体比例；
- 课堂观察给出行为锚点、观察者训练和课次边界；无双评数据不声称观察者一致性；
- 同时报告支持和不支持预期的结果；
- 区分相关、变化和因果；说明样本、周期、工具等局限。

## 五、证据链

每项已实施活动至少争取形成：方案/教案 → 任务单 → 过程记录 → 学生作品 → 评价量规与结果 → 教师反思 → 必要的照片/视频索引。照片要有日期、场景、活动和授权信息，不能只作装饰。

建立证据编号，例如 `OBS-2026-01`、`INT-T03`、`STU-WORK-C2-05`，在分析报告和研究报告中可追溯引用。

手写原件扫描后按记录ID和页码建立索引。OCR/人工转写是检索副本，不替代原件；分析引用必须能回到具体扫描页。空白工具、已填记录、转写稿和分析报告使用不同文件名与材料ID。
