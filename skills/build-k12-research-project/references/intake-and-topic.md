# 信息采集与选题

## 一、最小信息表

| 类别 | 字段 | 处理规则 |
|---|---|---|
| 教师 | 姓名、职称、职务、研究专长 | 未提供不得虚构 |
| 单位 | 学校全称、县市、城乡/校情 | 学校名称全套统一 |
| 教学 | 学段、主学科、实际关联学科、教材版本、年级班级、人数 | 班级可后补，但研究对象必须明确；跨学科不等于罗列学科 |
| 问题 | 具体场景、典型表现、影响、已有证据 | 把“想提升”改写成可研究问题 |
| 基础 | 已有做法、成果、资源、合作人员 | 用来判断可行性和创新起点 |
| 申报 | 年份、级别、管理单位、周期、通知/模板 | 不清楚时先检索当年官方信息 |
| 偏好 | 想做的方向、希望产出的成果、工作量 | 控制选题规模 |

## 二、方向生成法

从“学科关键问题 × 学生真实困难 × 可实施策略 × 地方/学校资源”组合方向。优先小切口、可行动、可取证、能迭代的校本研究。

方向推荐须读取[subject-specific-evidence.md](subject-specific-evidence.md)，随主学科调整可取得证据和风险：语言学科看作品/表达及修改，数学看思维步骤与错因，实验学科看原始测量和安全，政史地看权威来源与时空证据，艺体看过程性表现/作品与授权，信息科技看源文件/版本日志，劳动实践看规范操作与真实使用，心理健康/德育看保密和解释边界。不能给所有学科都默认配置同一份满意度问卷。

每个候选方向包含：

1. 规范拟题；
2. 要解决的一个核心问题；
3. 研究对象与边界；
4. 可操作的核心策略；
5. 可收集的过程和效果证据；
6. 预期成果；
7. 创新点；
8. 难度、风险和推荐指数。

用 100 分评估：问题真实性 20、政策与课标契合 15、研究价值 15、可操作性 20、证据可得性 15、创新性 10、题目规范性 5。分数不是结果本身，要用文字解释关键取舍。

## 三、题目结构

常用结构：

- 核心素养视域下＋研究对象＋教学策略/模式＋实践研究；
- 基于某理论/技术/资源＋某学科具体内容＋行动研究；
- 某真实问题导向的＋某能力培养＋策略研究；
- 地方文化/乡土资源融入＋某课程内容＋实践研究；
- 某学段某学科＋某一关键困难＋改进研究。

避免：

- “浅谈、刍议、探索”而没有对象和策略；
- 同时研究教学模式、评价体系、资源开发、教师成长等多个中心；
- 仅替换“新课标、核心素养、数字化”等热词；
- 没有对照或长期证据却使用“显著提高、有效促进”等强因果题目；
- 题目对象超出一个课题周期和团队能力。

## 四、确认节点

先交付方向对比表。用户选定或修改后，复述最终题目、研究对象、核心问题、主要策略和预期成果，请用户确认。确认后题目进入主清单；后续若变更，必须同步更新所有材料并保留变更说明。
