# 学科事实、成果署名与实施质量

本文件用于教学设计、案例、研究报告、成果汇编和结题终审。格式正确不能替代知识正确、来源真实和实施真实。

生成全学科材料或根目录注意事项文件时，同时使用[subject-specific-evidence.md](subject-specific-evidence.md)。该矩阵明确语文、数学、英语、理化生、政史地、音体美、信息科技/通用技术、劳动/综合实践、心理健康/德育等领域各自需要的真实原件、效果证据和专项风险；不得以统一的“课堂照片＋问卷”代替学科证据。

## 一、学科内容核验

每份教学或案例材料建立“学科事实核验表”：

- 对应课程标准版本、具体内容要求和行为动词；
- 教材版本、册次、单元、课时和学生已有知识；
- 核心概念、地图、数据、公式、单位、实验原理和结论边界；
- 主学科问题与关联学科知识分别由谁核验；
- 地方地名、历史文化、民族文化、物产、生态和安全事实的来源；
- 时政、统计数据和网络资源的发布日期、官方链接及核验日期。

国家版图、行政区划、时政人物和事件、人口经济数据、课程标准、食品健康、化学实验、灾害预警、航空航天等高风险内容必须使用权威来源。写作时尚未发生或未有权威报道的事件只能写成待核验素材，不能写成既成事实。终稿应保存来源页面或官方文件定位，避免链接失效后无法复核。

教学模型要说明模拟了什么、没有模拟什么。简易报警电路不是专业灾害监测预警设备；水火箭不是实际运载火箭；简易过滤不能证明达到饮用水标准；pH检测不能推出营养或医疗功效。跨学科内容必须经过相应学科教师或权威资料复核，不能为了“跨学科”牺牲科学性。

## 二、学段适宜与实施可行

- 任务难度、阅读量、计算量、工具操作和抽象程度符合年级；
- 一课时内容可以在实际时间内完成，课外活动明确时长和教师监管；
- 资源要求符合学校设备、网络、实验条件和经费，不把理想条件当作已具备；
- 为学习困难、残障或资源受限学生提供可执行替代方案；
- 不用政治、国防、劳动、文化等宏大表述替代地理或主学科的实际学习目标。

对每份教学设计做“时间预算”：导入、任务说明、探究、制作/实验、展示、评价和收束合计必须等于课时。材料准备、跨学科协调和校外审批另列，不挤入课堂时长。

## 三、时政、图片和版权

时政视频、新闻、地图、统计图、教材截图、诗文、论文图表和网络图片登记作者/机构、题名、发布日期、链接、访问日期和允许用途。只使用必要节选，避免复制整篇文章、整首作品或来源不明图片。对外发布时核对版权、肖像和平台使用规则。

正文不要只写“央视视频、网络资料、有关研究”。具体到官方标题、日期和来源；如材料用于比赛或长期课题，应在临近授课/提交时再次确认链接仍有效、事件表述仍准确。

## 四、作者、成员和成果归属

建立“贡献与署名登记表”：成果ID、题名、原作者、课题角色、实际贡献、是否为立项成员、外部协作者、原始版本、改编来源、授权状态、最终署名和确认日期。

- 课题负责人不能自动署名全部成果；署名按实际贡献和管理要求确定。
- 非立项成员的课例或资源可以作为经授权的合作材料，但必须说明来源、角色和授权，不能直接包装成课题组原创成果。
- 复用公开课、比赛稿、往届课题或网络模板时保留来源和改编记录，逐项清除旧教师、旧学校、旧年份和旧项目题目。
- 已发表、获奖或推广成果必须有真实证明；同一成果不得通过改名重复计算。
- AI可辅助整理和生成草稿，但不能成为作者，也不能代替负责人对事实、数据、引用、伦理和最终文本承担责任。

## 五、案例状态与实施基本信息

每个案例只能标记为以下一种状态：

- `designed`：完成设计，尚未试教；只能写预期表现和计划证据。
- `piloted`：小范围试教；写明试教时间、对象和修改点，不外推效果。
- `implemented`：按方案正式实施；必须有实施基本信息和原始证据。
- `validated`：实施后有相称的过程与结果证据，并完成复核；才可形成效果结论。

标记为`implemented/validated`时，必须填写：实施日期、学校、年级班级、课时、授课/指导教师、参与人数、实际任务、材料版本、偏离原方案事项、证据ID、数据截止日期和反思。缺少这些字段时自动降为`designed`或`piloted`，不能使用“学生普遍认为、活动提高了、结果表明”等表述。

案例中的“预期学习成果、实际学习成果、实施反思”必须分栏。不能一边写“预期”，一边无原始记录地叙述已经取得的效果。

## 六、干预实施保真度

研究效果取决于策略是否真正实施。建立实施保真度表：

| 字段 | 说明 |
|---|---|
| 核心成分 | 该策略不可缺少的教学行为/任务 |
| 计划剂量 | 课次、时长、频率和周期 |
| 实际剂量 | 真实完成的课次、时长、频率 |
| 覆盖对象 | 计划与实际参与人数、缺席和流失 |
| 执行质量 | 观察量表、学生投入、教师反思 |
| 偏离与原因 | 时间、设备、人员、校情导致的变化 |
| 证据 | 教案版本、观察、作品、评价、照片ID |

实施不足时，研究报告应先说明“策略未完全实施”，不能把没有出现预期效果简单归因于学生，也不能把局部成功写成整体有效。

## 七、成果承诺核销

从申请书提取全部阶段成果和最终成果，建立核销表：成果ID、申请书原名称、责任人、计划日期、实际文件、状态、证明、变更审批和是否进入结题目录。

最终只允许：

- `fulfilled`：成果已形成，文件、作者、日期和证据完整；
- `changed-approved`：成果经批准变更，附变更依据和替代成果；
- `not-fulfilled`：未兑现，如实说明原因。

不得静默改名、用多份教案替代承诺的研究报告，或把计划成果写成已经发表/推广。结题前逐项核销，所有`not-fulfilled`均进入问题与变更说明。
