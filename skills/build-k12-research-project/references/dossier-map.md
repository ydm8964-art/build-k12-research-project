# 完整课题材料图谱

## 一、逻辑主线

政策与课标提出方向；教学事实形成问题；申请书提出研究承诺；开题报告将承诺排成行动；研究工具收集证据；分析报告形成诊断；干预框架回应诊断；课例与案例实施框架；作品、评价、观察和反思证明过程与变化；研究报告综合回答研究问题；结题材料核对承诺与成果。

## 二、材料层级

| 层级 | 核心材料 | 主要功能 | 上下游约束 |
|---|---|---|---|
| 政策依据 | 申报通知、管理办法、课标、立项通知 | 确定资格、格式、时限 | 约束全部材料 |
| 设计立项 | 申请书、活页、论证材料 | 定义问题、目标、内容、成果 | 成为项目总纲 |
| 组织实施 | 开题报告、实施方案、分工、进度表 | 把总纲转为行动 | 约束工具和活动 |
| 研究工具 | 问卷、访谈、观察、测评、变量编码表 | 把问题转为指标 | 对应每个研究问题 |
| 原始证据 | 原始问卷/数据工作簿、录音转写、观察表、照片原件及登记、作品 | 证明研究真实发生 | 支撑分析和结论 |
| 诊断分析 | 问卷、访谈、观察、测评分析 | 从证据得到问题与原因 | 产生干预需求 |
| 实践干预 | 策略框架、教学设计、活动方案、任务单、量规 | 实施解决方案 | 回应诊断结果 |
| 过程管理 | 会议、培训、阶段总结、中期报告、变更材料 | 证明持续推进 | 记录计划与现实差异 |
| 成果结题 | 研究报告、案例集、论文、资源包、结题申请、鉴定书 | 回答问题并验收承诺 | 汇总全部证据 |

## 三、必要与条件性材料

必须以当年管理部门清单为准。一般情况下，申请书、开题报告、研究报告、成果证明和结题申请属于核心材料；学生问卷、教师问卷、访谈、课堂观察、前后测、案例集等是否使用，取决于研究问题和方法，不为凑数量机械添加。

若结论声称学生变化，至少需要学生层面的证据；若声称教师变化，需要教师层面证据；若声称课堂方式改变，需要课堂观察或课堂实录；若声称成果推广，需要应用单位、使用记录或反馈。

## 四、材料依赖矩阵

- 目标：必须对应研究内容、方法、阶段活动、成果和结论。
- 研究内容：必须对应工具或实践任务，不能只写在申请书中。
- 工具指标：必须来自研究问题和核心概念，不凭空堆题。
- 分析结论：必须追溯到原始数据；不同来源可三角互证。
- 干预策略：必须针对诊断问题；每项策略有活动载体。
- 实施活动：必须留下过程记录、学生成果或评价证据。
- 最终成果：必须对应申请书承诺；变化需说明并履行变更程序。

## 五、交付目录建议

根目录先放`00_课题材料包注意事项_真实性与待办清单.docx`，再按 `01政策与立项/02申报/03开题/04研究工具/05原始数据/06分析报告/07实践方案/08课例案例/09过程管理/10成果与结题/11附录证据` 组织。`11附录证据`下可再分`照片原件（受控）/照片派生件/照片证据册/授权与审批状态/作品与证明`。每份材料标注版本、日期和状态，避免“最终版、最终修改版2”等不可追踪命名。

`05原始数据`中至少维护一个XLSX数据工作簿或等价的可审计数据文件；Word分析报告不得成为唯一的数据存放位置。材料目录同时登记每份文件的`output_format`、`format_profile`、权威模板、版本和验收状态。

用户要求一次生成全套时，按[one-shot-generation-protocol.md](one-shot-generation-protocol.md)选择成套范围，并运行`audit_lifecycle_coverage.py`。参考材料缺失的中期、伦理/同意、数据工作簿、学生效果、研究总报告和结题管理材料仍属于应规划角色，不得照着旧文件夹的缺项生成。
